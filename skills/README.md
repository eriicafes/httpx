# Httpx Skills

Reusable AI agent skills for building with [httpx](https://github.com/eriicafes/httpx).

## Install

```sh
npx skills add eriicafes/httpx
```

## Available Skills

| Skill | Description |
|---|---|
| [`httpx`](./httpx/SKILL.md) | Error-returning handlers, mux composition, middleware, prefixes, graceful shutdown, request helpers, and where to look for `openapi`, `session`, `httperrors`, and `contextkey` details |
